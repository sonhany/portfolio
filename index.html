The homelab

Everything on this page — and every tool I study with — runs on hardware I own.

fnOS NAS (Dell tower)

Docker host for: new-api (LLM API gateway for my research scripts), NetBird (WireGuard mesh for secure remote access), a DDNS renewal bot, and nginx serving this page.

Why self-host?

Data stays home, services stay up, and every failure is mine to fix — which is exactly how you learn networking, containers and DNS for real.
